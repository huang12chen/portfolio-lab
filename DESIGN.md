# Alex Lin — Portfolio UI Design

A fictional bilingual portfolio for an AI Product & Growth Lead. The reader should recognise the person's focus, scan the three distinct cases, and enter one complete case with one click. This is an open-source teaching example, never evidence of a real person's career.

## Visual direction

Use a paper/forest palette, serif/sans hierarchy, wide centred container, compact project overview, native case links, rounded controls, local motion library, stable pointer hit areas, full-media presentation and explicit return navigation. Content and imagery suit product/growth work. Keep body text readable at 17px, with clear title hierarchy and 44px controls.

Paper #f4f5ef; forest #233b32; surface #e7eadf; muted #59675c; acid-lime #dfef85; warm-white #fffdf8. Accent lilac #dedcf3 and ochre #e8bd72 distinguish case covers. Max content 1320px, reading column 800px. Rounded stages 28–36px; controls 999px or 12px as their use requires. English display Georgia/serif, interface system sans; Chinese system serif/sans fallbacks. All fonts and animation assets are local/system.

## Content and navigation

Home: Alex identity and useful-outcome proposition → fictional career context → three compact cases → working approach → about/build-your-own path. Signal shows a synthetic interactive growth dashboard; Briefly is an editable deterministic local content workflow; Fieldwork explains product trade-offs with an inspectable concept comparison. Every case includes task, role, artifact/demo, reasoning and limitations. About contains the coherent fictional 2020–2026 timeline, capability mapping and build notes.

Native index.html, project.html?id=signal|briefly|fieldwork, about.html. Locale query lang=en|zh retains current project/hash and does not depend on storage. No required preview modal, login, API key or external service. Core artifacts are inline; optional downloads expose the actual synthetic data or sample résumé. No fake email, dead contact action, invented live integration or real-client endorsement.

## Interaction and responsive behaviour

Use pressure feedback, subtle card tilt, elastic filters and motion pause/reduced-motion. All input/scroll areas remain stationary and touch-friendly. Dashboard market/period controls update actual synthetic chart, table and metrics; forecast assumptions are displayed. Brief input changes actual locally computed output; errors and clipboard failures are visible. English/Chinese locale affects labels, ARIA and number display. Desktop overview has three comparable cards; mobile stacks them without hiding content. Dense demos reflow rather than shrink text. Complete photos, diagrams and screenshots keep their ratio; mobile menu closes with Escape and returns focus.

## Verification

Check real browser at 1440/2559 wide desktop, 768 tablet and 390/360 mobile; direct case load, locale persistence, filters, native Back, demo math, keyboard, reduced motion, image decoding, public bundle privacy and root/subdirectory hosting. Browser screenshots document the running example; Node tests cover state/math and local server path boundaries. Synthetic career figures, illustrative research and prototype capabilities stay explicitly identified at the point of use.

## Alternative reading route

The optional story.html uses the same fictional material as the gallery so the reader can compare reading paths. It exposes every core prototype and project summary inline, with native chapter anchors and optional deeper cases. A dark forest canvas, original CSS3D interface layers and bounded scroll/pointer shifts create depth; no WebGL model or remote AI service is connected. Essential text and controls remain usable without the optional effect files. This comparison is an example, not a requirement that other portfolios use two variants.
