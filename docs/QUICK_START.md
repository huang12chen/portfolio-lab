## Portfolio

把仓库地址或下载的文件夹交给你的编码工具，复制下面这段话，再发送简历、作品和目标岗位。

```text
请读取 Portfolio Lab 的安装说明，在当前项目安装 bespoke-portfolio。如果已有同名技能，先保留我的修改。

根据我接下来提供的简历和作品，帮我制作个人作品集。先挑选展示内容，写清项目里我负责的部分，再决定页面布局和风格。参考文章或网址时，请进入具体案例查看，不能只看网站名字。没有依据的经历和成绩留空。

做完后运行网站，检查手机排版、图片和主要按钮，给我预览地址和源码。如果我已说明部署要求，继续按那个要求完成。
```

Give your coding agent the repository URL or downloaded folder, then this prompt and your résumé, work samples, and target role:

```text
Read Portfolio Lab's installation guide and install bespoke-portfolio in this project. Preserve my changes if the Skill is already installed.

Build a portfolio from the résumé and work I provide. Choose what to show, explain my role in each project, then decide the layout and style. Open the specific cases in reference articles or websites. Leave unsupported career details and results blank.

Run the site and check its mobile layout, images, and main controls. Give me a preview and the source. Follow any deployment requirements I have already provided.
```

作品少也可以直接开始。有一两个完整项目，就先讲清这些项目；不用凑成三个。客户名称或联系方式需要保密时，一起说明。

You can start with one or two complete projects. There is no need to invent more. Tell the agent if client names or contact details should stay private.

To view the existing example, download the source and run this from its root. No Skill installation is needed:

```sh
npm run dev
```

Requires Node.js 22+. Open the [gallery](http://localhost:4180/index.html?lang=en) or [scroll version](http://localhost:4180/story.html?lang=en). Ctrl+C stops the server.

这是 Alex 的虚构示例。制作自己的作品集时，把自己的材料交给 Skill，或替换网站里的示例内容。

This is Alex's fictional example. To make your portfolio, provide your own material to the Skill or edit the sample site.
