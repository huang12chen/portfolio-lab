# Sharing and privacy / 公开分享与隐私

This repository's persona, résumé, case narratives, business numbers, and research are fictional. It deliberately keeps personal originals and hosting administration outside the shared project. Stock photography is attributed in the asset register.

本项目使用虚构人物、履历、案例、商业指标与调研，个人原件和托管管理信息保留在共享目录之外；图库照片另有来源与许可。

## Before publishing your own fork

- Review every file you intend to publish, including old Git revisions. Ignoring a file now does not remove it from existing history.
- Keep private résumés, employer/customer screenshots, raw analytics exports, recordings with account menus, browser profiles, cookies, environment files, and hosting credentials outside the public tree.
- Inspect image and recording pixels as well as metadata: account names, tab titles, notifications, addresses, email, and contact details can appear in media.
- Attribute third-party assets and retain their terms. A public example should not turn an employer's artwork into the maintainer's original art.
- Use contact details only when you intend to publish them. Replace fictional material with supported claims; retain disclosure for anything still invented.
- If private material entered Git history, make a separate sanitized export and audit it before a first publication. For already published secrets, revoke or rotate them; merely deleting the latest file is insufficient.

公开前检查文件、历史、媒体画面和元数据。已忽略文件可能仍在 Git 历史中。私人材料留在共享目录外；若秘密已公开，先撤销或轮换，不能只删除最新版本。

The included release packager uses a public-file allowlist and rejects recognizable credentials, local private paths, and forbidden private file types. It cannot recognize every person's private information and does not replace review of your content. See [release packages](RELEASE.md).

## What the example sends

The included demo has local scripts, fonts, images, and sample data; no analytics, account connection, model API, or contact submission is configured. The portfolio Skill researches websites relevant to your request using tools supplied by your agent. Your agent and hosting provider have their own data handling; this repository does not authenticate those services or supply their credentials.

示例没有配置统计、账号连接、模型 API 或联系表单提交。参考研究会按任务访问外部网站，工具来自所用智能体；智能体和托管平台的数据处理由其各自约定决定。
