# Security and privacy reports / 安全与隐私报告

Do not include credentials, private résumés, customer data, account cookies, or personal screenshots in a public issue. If GitHub's **Security → Report a vulnerability** control is available on this repository, use it for a private report. If it is unavailable, use the relevant GitHub abuse/privacy reporting channel; a public issue can request a private contact method without exposing sensitive details.

不要在公开 Issue 中提交凭据、简历、客户资料、Cookie 或个人截图。仓库若提供 **Security → Report a vulnerability**，请私下报告；没有时使用 GitHub 的相关滥用或隐私渠道，或仅公开请求私下联系方法，不附敏感内容。

Describe the affected file or route, version, impact, and a minimal reproduction using synthetic data. This project contains static browser examples and agent instructions, not a hosted account or model service. Review changes on your chosen agent and hosting platform before deployment. There is no guaranteed response time or commercial support commitment.
