# Community conduct / 社区行为规范

Treat contributors respectfully regardless of background, language, identity, or experience. Discuss ideas and code in good faith; give specific, constructive feedback. Harassment, threats, discrimination, spam, impersonation, and publishing another person's private information are not accepted.

尊重不同背景、语言、身份与经验的参与者，就内容和代码提出具体建议。不得骚扰、威胁、歧视、刷屏、冒充他人或公开他人隐私。

This applies to project issues, pull requests, and other project-managed spaces. Maintainers may edit or remove harmful content, restrict participation, or block accounts using GitHub's moderation controls, with action proportionate to the conduct.

For abuse, use the relevant GitHub content or user's **Report abuse** control. For sensitive security or privacy disclosures, follow [SECURITY.md](SECURITY.md) instead of posting private details in a public issue. This policy does not promise a private project-specific reporting inbox or immediate response.
