# Portfolio Refinements

[简体中文](zh-CN/review.md)

Use these problem-and-response pairs to improve a portfolio. Choose the relevant checks for the material and audience; individual style preferences remain conditional.

| Problem | Transferable response and check |
| --- | --- |
| A recommended site was known only by name | Trace article → resource → case or component → relevant original; distinguish access from exercised interaction |
| The site felt like a résumé without work | Build cases from material, contribution, process, and outcomes; use biography and experience as support |
| Numbers lacked a visible basis | Show matching screenshots or deliverables with metric definition and period nearby |
| Many accounts made selection unclear | Curate representative evidence; label any summed follower count as undeduplicated and dated, never unique audience |
| Pre-departure screenshots looked current | Preserve the confirmed time semantics; a snapshot is not current size or growth |
| Employer assets resembled personal authorship | Attribute the source and individual responsibility; presentation does not establish sole creation |
| A name or email was intentionally withheld | Leave it empty and respect the choice; do not complete a real person's profile with false identity |
| Unpublished work was not intended for hosting | Respect asset-level scope; local material does not automatically enter a public package |
| Future image or video quantity was unknown | Finish a useful structure for existing content without empty slots; adapt to real volume later |
| Irrelevant “AI concept cover” labels distracted | Remove production labels that do not help judgment; retain material source or illustration labels that do |
| Typography and headings were inconsistent | Align roles, line heights, weights, and script coverage using real copy |
| A user wanted softer button shapes or sizes | Treat shape as a brand choice; unify controls without universally mandating pills |
| Pointer feedback disappeared on movement | Check center and ring contrast on light and dark surfaces; preserve stable hit areas and native usability |
| Hover showed only a large ring without press feedback | Check enter, link, press, release, and leave behavior rather than only static screenshots |
| Effects moved the clickable target | Animate inner content and keep the outer hit area stable; remeasure after scroll |
| More expressive feedback was requested | Choose suitable magnet, tilt, spring, glow, or press behavior and check reset and reduced motion |
| A fluid button or drawer was requested | Inspect a running example and connect it to a real action rather than inventing a workflow for an effect |
| The result copied a reference too closely | Adapt relationships and principles to this person's content; exclude others' logos, copy, and assets |
| Oversized footer type competed with the work | Keep secondary contact subordinate to the main reading path; size it for the brand and content |
| Decorative labels and symbols overwhelmed the page | Remove unhelpful decoration while preserving meaningful punctuation and semantics |
| All and a category showed the same results | Make real differences visible and ensure effective filtering and selected feedback |
| Long project sections hid the overall collection | Start with an overview; compare a small collection or curate a large one with an index |
| Entering a case required another click | Open the complete case with core material expanded; make zoom and supplements optional |
| Readers could not find their way back | Show the current project, a clear project-list return, and specific related projects; test native Back |
| Work navigation from biography landed halfway down a page | Define destinations consistently; distinguish home top from the work section |
| Contact required returning to another site to exit | Close a temporary panel in place and restore focus and scroll |
| Navigation text duplicated or ghosted | Check shared transitions and page snapshots; keep normal navigation if the effect is unreliable |
| Images intermittently failed in the browser | Use bounded retries and a visible alternative; check decoding and canvas lifecycle |
| Portraits were cropped into banners or squares | Use complete proportions or a contain stage and check all edges after animation |
| A nominally centered layout still felt arbitrary | Align the group, subject, and reading column separately; connect images to explanations |
| Body text occupied an awkward side of a wide page | Use a suitable centered reading column with left-aligned text; do not center every paragraph |
| The opening did not communicate the available work | Combine position and overview with concrete names, role, material, and outcome at case entry |
| One desktop size worked but mobile or wide screens did not | Include the reported size, representative widths, long copy, and real media; no overflow does not mean no cropping |
| A control-looking label was only an illustration | Make illustrations descriptive; primary actions must actually work |

Use these lessons to spot related risks, then choose the implementation for the current reader and material. They do not make one person's layout, palette, project count, or motion preferences a universal template. For authorized fictional demos and public sample releases, use the separately scoped [demo and release reference](demo-projects.md).
