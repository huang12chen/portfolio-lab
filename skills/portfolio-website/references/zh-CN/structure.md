# 行业、数量与案例适配

以下是决策起点，不是职业模板。先看一个人的实际材料与目标，再决定结构。相同行业、不同目标应得到不同网站。

[English version](../structure.md)

## 数量影响入口，不规定风格

| 材料规模 | 可能的组织方式 | 不应做的事 |
| --- | --- | --- |
| 0 个正式项目 | 经历与方法、自主练习、过程材料；明确状态，按需补做真实示例 | 捏造客户和结果，把待完成项目画成成品 |
| 1–2 个强项目 | 单页深讲或少量完整案例，介绍与联系辅助 | 为凑三列复制同一作品、制造空位 |
| 3–6 个项目 | 可快速比较的概览；在项目差异清楚时提供分类 | 让读者滚完第一个大横幅后才知道还有其他项目 |
| 7–20 个项目 | 代表案例加完整索引，分类来自真实差异 | 所有内容同等放大、制造无效标签 |
| 20 个以上素材 | 按系列/能力/主题策展，精选入口与完整集合分工 | 每张照片都变成独立的长案例；默认加载所有大图 |

一个项目可有很多素材，很多作品也可能属于一个系列。先归组，不把文件数量直接当项目数量。分类与筛选仅在确实帮助选择时使用。

## 领域与证据

| 领域/读者任务 | 有说服力的材料 | 可探索的呈现 |
| --- | --- | --- |
| 设计、艺术、摄影、建筑 | 原图、成组作品、尺度/场景、过程、本人角色 | 尊重比例的画廊、系列页、杂志式编排；必要时细节放大 |
| 开发、产品、工程 | 真实 demo/录屏、代码、架构、约束、测试与取舍 | 运行结果先行，界面与实现说明邻近；仓库是补充入口 |
| 研究、教育、医疗、公益 | 问题、方法、匿名材料、结果、反思 | 清楚的编辑排版与图表；敏感内容最小展示，不虚构照片 |
| 内容、写作、媒体 | 文章/脚本、节选、视频、不同受众的表达 | 可读节选与完整作品链接，按主题或能力组织 |
| 运营、销售、市场 | 商品页面、内容样例、账号记录、活动方案、口径明确的结果 | 证据与过程并重；指标摘要帮助扫描 |
| 咨询、服务、管理 | 交付物、框架、过程、关键决策、团队边界 | 案例叙事、脱敏交付片段、服务能力与联系方式 |
| 转行或学生 | 自主项目、练习、课程成果、可迁移能力、反思 | 真实状态清楚，展示判断和成长；不伪造商业经历 |

这些方向可交叉。不要因为某个职业就自动选择严肃蓝或炫酷黑；用作品的色彩、材料、读者与个人特点形成设计。

## 案例主线可变

可从“任务、贡献、材料、方法、结果、边界”中选择和合并段落。视觉作品可以先看作品，再读过程；复杂技术项目可以先看可运行结果；研究可从问题与主要发现进入；写作者先给可读片段。

主标题说具体项目，辅助句补充定位。指标并非所有行业必需，有据的定性结果也可以。没有结果数字时，讲明实现、交付和判断，不填假 KPI。

## 三种不同的组合示例（示意）

- 只有两项匿名研究报告的申请者：低装饰的阅读首页、两个研究摘要与方法/图表入口，长文有目录，不需要图片轮播。
- 有四十多张不同尺寸作品的摄影师：按系列策展，少量代表作建立风格，图片网格尊重比例，进入系列后完整看图。
- 有四个产品工程项目的开发者：清楚的项目概览，真实运行画面和职责/约束并列，案例中展开架构与取舍；源码链接直接可达。

示例只说明推导关系，不复制到所有人身上。

## 先选择阅读路线，再选择特效

项目索引与连续叙事服务于不同的阅读任务。根据真实作品数量、读者是否需要比较选择，以及每份材料的查看成本决定。

- 连续滚动页可以直接呈现每个项目的问题、本人职责、核心材料、判断与结果。交互原型可就地操作，深入细节作为可选路径。
- 索引适合在多个不同项目或系列间选择。预览要说明内容，一次有意义的选择就进入完整案例；也可采用短摘要加深入案例的混合结构。
- 保持原生滚动、普通链接、有意义的锚点，以及返回离开位置的路径。固定章节导航需检查宽而矮、宽屏和手机视口，不能只看高桌面截图。

3D、视差和转场属于呈现选择，不是作品集水平的排名。需要表达素材或帮助理解连续关系时使用，并保留清楚的静态内容、稳定控件、触屏和减少动效方案。比较两个方向时，使用同一份内容更容易判断阅读与视觉差异；无需强迫每个人都制作两站。
