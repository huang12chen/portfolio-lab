# 虚构演示与公开交付

[English version](../demo-projects.md)

用户已授权虚构教学作品集、互动演示或可分发示例时按需阅读。本参考补充通常的真实材料流程，不要求每个作品集都变成演示包或双语站。

## 分清真人与虚构模式

真人作品集保留有依据的任职、贡献、作品和结果。材料缺失是待补的事实，不是编造职业经历的许可。

用户已明确授权虚构模式时，按现有范围继续，不另加普通审批。清楚标记虚构的身份、任职、业务指标、调研以及客户/雇主材料。模拟调研属于情景假设，不能写成实际访谈或已观察到的用户行为。整体说明应容易找到，容易混淆的材料旁再作具体标记。虚构内容不能迁移到真人简历、个人站或事实案例。

一个可操作的演示可以是真实完成的实现，同时品牌、数据与情景仍属虚构；两者分别说明。

## 在独立副本中复用成熟网站

以已有个人站为起点时，先备份原站与素材，并核对预期文件或校验和，再在独立副本中改造。选择性复用有效的通用布局、tokens、控件和动效，用已授权示例替换个人内容。

私有制作证据与可分发项目分开。公开副本不继承个人信息、未公开素材、凭据、账户/站点标识、分析身份、部署目标或原仓库历史。如需新的公开仓库，从准备公开的文件初始化，不复制原 `.git`。保留原站受众与托管配置；完成演示不代表获准替换个人站或对外发布。

## 让交互可以实际检查

交互能帮助读者判断作品时，可以做真正可运行的浏览器原型。主操作应真实发生：输入可以编辑并改变输出；筛选同步改变相应指标、图表与记录；重置、本地下载执行其名称所述动作。

在演示附近说明能力边界：

| 实现 | 需要说清楚 |
| --- | --- |
| 本地模板 | 输出来自本地规则或模板，不暗示调用外部模型 |
| 模拟数据或情景 | 明示合成来源、单位、周期、计算与预测假设，不暗示实时账号或真实业务成果 |
| 真实服务集成 | 说明实际连接的服务和已获授权、亲自验证的端到端操作；配置完成或 mock 不等于完成真实调用 |

不使用假模型进度、虚构调研结论或貌似证明成功的装饰结果。同步模板可以立即完成；加载、停止与取消只对应确实存在的工作状态。控件保留语义、触屏可用性，图表提供文字摘要；未去重事件/账号合计不能写成独立人数。

## 保持显示稿与导出稿一致

决定结果的关键输入改变后，把当前结果标为上一版草稿，在重新生成或明确恢复前禁用旧稿复制与下载。不能屏幕显示新稿，却静默导出默认稿或更早版本。

显示、复制与下载使用同一份当前结果。重复初始化不叠加事件。清理后重新挂载同一 DOM 时，保持当前稿和待更新状态一致，或明确同时重置输入与结果；旧挂载中尚未完成的剪贴板/生成回调不能覆盖新挂载状态。

回归应核对实际复制/下载内容及旧稿状态，而不只数监听器，并说明实际测试范围。

## 按实际需要适配语言与地区

语言和市场由任务决定，不强制每个项目中英双语。增加语言时，按实际功能覆盖正文、导航、ARIA/控件名称、状态/错误、日期、货币单位和下载结果。

有对应内容时，切换语言保留当前案例与有效锚点。缺少译文时提供明确替代，不静默跳到无关页面。界面语言、市场和货币分别处理；模拟地区统一显示一种货币时，不暗示已按真实汇率换算。用选定语言检查长标签、混排、键盘与路由历史。

## 准备可维护的公开示例

用户授权开源交付时，准备：

- 素材来源、适用许可与署名，包括处理后的图库图片。能够下载或复制不代表取得再分发许可。
- 面向国际用户的英文入口，以及适用于本次交付的其他语言说明。用可移植路径解释安装、运行、限制与维护。
- 实际运行示例的截图，说明对应视图或状态。浏览器证据与单元/静态检查分开；不用虚构截图证明运行成功。
- 对应真实产物和托管路线的部署说明。本地可运行、包已准备好与成功发布分别报告。
- 没有个人信息和私有制作材料、可修改内容/路由/素材/逻辑的清楚示例。

分发前核对公开包内容。实际问题或具体交付需求才形成新规则；一个示例的配色、人物、案例数量、行业或技术选型不应成为所有人的模板。
