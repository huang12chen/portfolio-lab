# 材料、贡献与证据

## 最小可用画像

从现有资料中提炼，不要求每次填表：目标读者与用途、核心能力、项目/作品及其数量、每项职责、可用媒介、期望风格、公开范围、技术/维护条件。已有授权和偏好持续有效。

材料可以是简历、客户交付、摄影/设计、文章、研究报告、仓库、产品界面、运营截图、视频、流程、失败复盘或自主练习。它们有不同的证明力，不按“有没有漂亮图片”决定是否值得展示。

## 主张与材料对应

为关键主张保留可追踪关系；字段按当前材料使用，不强制补齐不存在的数据：

| 字段 | 作用 |
| --- | --- |
| 项目/任务与背景 | 读者理解当时要解决什么 |
| 本人负责的部分 | 区分独立完成、协作、运营、设计、实施与素材使用 |
| 实际材料 | 文件或原链接、时间与原始版本 |
| 拟展示的主张 | 准备写进页面的具体描述 |
| 指标与口径 | 数值、单位、范围、时间窗和依据 |
| 可见范围 | 可公开、脱敏、仅本地、暂留空 |
| 限制/未知 | 尚不能从材料证明的内容 |

用“参与商品运营与素材组织”描述该贡献，不能因素材在项目里就声称画作由本人独立创作；相反，也不要把真实承担的工作缩减成“协助”而丢失细节。

## 各类证据的边界

- 数量快照不自动代表增长，播放量不等于粉丝，平台粉丝不直接相加成独立人数。截图中的近 30 天指标保留其时间窗。
- 历史截图标注对应时点；离职前保存的记录不能写成当前账号规模。无法确定日期可保留用户确认的相对时点。
- 销售额/GMV、利润、订单利润率、毛利和净利区分。没有归因记录，不声称某条内容直接带来成交。
- 工具的流程说明、概念图、软件实拍/录屏、基准测试分别标明；没有计时记录就不编造节省比例。
- 客户作品、雇主项目和团队成果注明来源及个人角色。用户已确认的使用范围无需重复询问；确有不明确的公开限制时，只澄清相关部分，继续完成其他内容。
- 需要脱敏时保留原件，导出展示副本并记录裁剪/遮挡；不修改指标或重造截图。无关通知、生日、推荐账号等不必进入作品集。
- 合成示意可以帮助解释，但不能替代真实结果。概念项目和自主练习明确标识，避免伪装成客户交付。

## 缺材料时继续推进

说明哪类材料能增强哪条主张。例如运营案例补上架页面或账号记录，开发案例补运行画面，研究案例补方法与结果图。先组织已有材料、完成设计和可用版本，避免靠一排未知占位框暗示作品齐全。

姓名、邮箱、定位、社交账号按用户选择公开。使用占位文本只限明确的临时设计预览，最终展示不得把虚构身份当真。
