# 一眼是生成的

模型做出的作品集共享一小撮破绽，而这些破绽不是品味失败——它们是"答错了问题"留下的可见残留。当搭建者问的是"这一节需要什么"而不是"这份材料里有什么"，破绽就出现。编号眉标填的是一个槽；三张等宽卡片填的是一个槽；标题背后那团渐变填的也是一个槽。槽之所以安全，是因为它永远不会与内容冲突；而它之所以被读成生成的，原因恰恰是同一条：槽里的任何东西，都不可能是只对这个人成立的。

本文件是这份残留清单，外加一项任何单个评审都看不见的测量：两个人的网站看起来像一个人做的。[视觉方向](visual-direction.md) 给的是方向声明的替换测试；这里给的是**成品**的替换测试。

## 元素级的出处规则

下面这张清单里大半内容，都可以被这一条检查化掉：**成品页面上每一个可见元素，都必须能追溯到材料里的一个事实或读者的一项任务，而且这个追溯要能用一个短语说出口。**"装简历的那个容器"说的是任务。"一排装饰用卡片"说的是槽。"Signal 数据集里那四周的数字"说的是事实。"找几个数填满指标条"什么都没说；而如果你说不出它是什么，这个元素就是来自你见过的某个模板。

一个元素之所以活下来，只是因为删掉它版式上会留个明显的洞——那它就是槽。一个元素活下来是因为读者需要它——那它才是内容。下面每条检查真正在探测的，就是这两者的差别。

## 清单

| 破绽 | 它填的是哪个槽 | 推导出来的答案长什么样 |
| --- | --- | --- |
| 一排三张或四张等宽卡片 | "特性"——一个给等重量内容的网格 | 作品并不等重。给它排序，或让数量取自材料自己有几个案例，并让其中一个在结构上更大 |
| 每个标题之上的 `01 / 02 / 03` 眉标 | 次序，而次序已经是 DOM 顺序 | 只给真正有序的流程编号；扫读页面的人不需要一个数字才知道下一节在后面 |
| 一套系统无衬线包办所有角色——Inter、Geist，或操作系统默认字族配三个字号 | "干净的排版" | 层级于是只能靠字重撑，三级之内就塌。并不一定需要展示字体，但需要第二种*声音*，而它来自材料本身：器物上的刻字、读数用的等宽字、印刷纸张用的那副字面 |
| 眉题、标签、说明全都用全大写字距 | "编辑设计的收尾" | 编辑规范里这种处理只留给一个角色。三个角色一起用，它们就被压成一层，读者再也分不出节名和字段名 |
| 每个板块进场都 fade-up | "有动效" | 动效是关于什么重要的主张。只在两三个真的引导注意力的地方动，其余保持静止——见 [动效编排](motion-choreography.md) |
| 喊口号却不给出任何可核查陈述的首屏 | "一段开场白" | 第一行必须可核查：做了什么、为谁做的、改变了什么。`把想法变成优雅的解决方案` 是每个生成式站点都会用同一个形状填上的坑 |
| 暖纸底 + 一个土红强调色 + 衬线展示字 | "有品位" | 底色从材料自己的地面推导，强调色从一个具名采样点推导；修复师的页面和陶艺师的页面不能互换配色而无人察觉 |
| 近黑底 + 一个荧光强调色 | "技术感" | 同一条测试。这是上面那位的暗色孪生，同样可以跨人设无损搬运 |
| 标题背后一团渐变、极光或噪点场 | "现代" | 只在材料自己有的地方放肌理——纸纤维、窑具表面、原页的扫描件——并写明来源 |
| 任何包含中文的元素上有 `letter-spacing` | "设计过的标题" | 见[视觉方向](visual-direction.md)；被拉开间距的中文标题在任何字距值下都是缺陷，而工具会数这个 |
| 章节标题是抽象名词——流程、方法、影响、概览 | 模板自己的分区名 | 用这一节真正在说的话作标题：`顺序是固定的，判断是逐册的` 是标题，`流程` 是槽 |
| 一条指标带，没有时段、没有单位、没有出处 | "唬人的数字" | 每个数字在使用处都同时带值、定义、时段与归属，否则不展示 |
| 一个圆角令牌用在所有东西上 | "一致的设计系统" | 圆角是关于物件边缘的陈述：折页、机壳面板和输入框不是同一个转角 |
| 一个阴影用在每张卡上 | "有层次" | 见[表面、光与层次](surfaces.md)——层数取自材料的物件有几处相接 |
| 每一节上方一个圆底图标 | "有点视觉变化" | 图标只在读者会反复遇见同一物件、需要不读文字就认出它时才挣到位置；一个作品集大概只有两个这样的物件 |
| 每个列表都按序号统一错峰 | "动效设计" | 见[动效编排](motion-choreography.md)：只有当被介绍的是"整组"而不是次序时，错峰才成立 |
| 每张卡都 `hover` 抬起 4px 并加深阴影 | "可交互" | 反馈属于会回应的东西。一段证据不需要鼠标经过时就浮起来 |
| 每个项目下面几排胶囊标签 | "元信息" | 标签要么是导航手段，要么是装饰；点了没反应，它就是穿着控件衣服的装饰 |
| 四列页脚链接，其中几条无处可去 | "一个完整的站" | 页脚只放读者看完作品之后真会要的东西：联系方式、简历、来源、页面制作日期 |
| 两不等宽的东西被 `space-between` 推到两端 | "一行" | 对齐应当表达关系；把标签和它的值推到两端，是发明了一段没有意义的空隙 |
| 桌面、笔记本、陶土、书架的库存照片 | "这里应该有一张图" | 展示那件东西本身——作品、图、diff、数据——或者展示一个画出来的物件，并标明是画的 |
| 抽象地夸赞作者本人的文案 | "一段职业简介" | 写发生了什么、你决定了什么、代价是什么。`它慢、它抖、它贵` 是人在说话；"追求极致的问题解决者" 是槽 |
| 把设计系统摆在明面上：色板阵列、字样张、间距表 | "证明我懂设计系统" | 系统是页面的骨骼，不是页面的内容。只有当这个人真正的工作就是这套系统时才展示它 |
| 所有东西居中、同一个最大宽度 | "干净的版式" | 居中是在声明这个物件与旁边的东西没有关系。两个居中的块排成一列只有一条轴，而只有一条轴的页面是一份文档，不是一个构图 |

破绽不是禁令。材料里确实存在一组等重物件时，一排卡片就是正确的。永远不正确的是先伸手拿那个形状、再问材料里有没有——所以上表写的是该问的问题，而不是禁令本身。

## 相似度的测量，因为这一条你自己看不见

一个成品对一位评审，是赢不了的：上面每条破绽单独看都体面，这正是它们危险的原因。真正要紧的那个失败——两个不同的人的网站出自同一双手——只存在于**比较**里，所以它必须被测量而不是被品味。

把你的产出与上一份用同一技能做出来的东西比较；如果读过 `examples/` 里的示例，也和它比较：

- **强调色色相距离。** 取两个页面的主强调色与次强调色各自的色相，报告角度距离。由不同材料做出来的两个页面，在两枚强调色上都落得很近，那就是一套配色换了令牌名字——这正是本项目在"必须从材料采样"这条规则出现之前，实测跑出来的那件事。单看距离不是结论；距离近**加上**角色结构相同才是。
- **具名的颜色角色。** 比较两边的角色词汇表。若两个页面声明的是同一套角色、同一个底色家族，那么方向没有被推导过两次，无论色相差多远。
- **首屏骨架。** 比较块的种类顺序，以及每块占视口高度的比例。两个首屏顺序相同、比例相近，就不是从材料构图得来的，而是来自同一套内部模板。
- **不同取值的个数。** 数一数不同的字号、不同的字重、不同的圆角、以及阴影层数的不同取值。两份产出这四项计数几乎相同，说明它们在跑同一套系统，只是换了词。
- **标题的连续词重叠。** 比较标题文本。两个人设的站点之间共享的多词短语——尤其是抽象的那种——意味着文案是从同一个先验生成的。
- **成品级的替换测试。** 把你页面的标题与图换成另一个人设的，而不动版式、颜色与字体。如果什么都没显得不对，你的设计就是与内容无关的；而与内容无关的设计，按定义就不是从内容推导出来的。

**检查。** 对两份产出运行工具的比对，把上面六项测度连同数值一起写进验收记录——没有实测数值的比较属于自我报告，会被丢弃。门槛不是"差异最大化"：后端工程师和数据分析师本来就可以合理地做出相似页面。门槛是**每一个被共享的属性都能由这两人材料中的一个共同事实解释**，而任何你解释不了的共享，就是本文件命名的那种残留。

## 顺序

在成品存在之后、被称作完成之前跑这一份，因为上面每一条都是对渲染出来的页面的比较，不是对意图的比较。先修有可追溯成因的那些：没有时段的指标是内容缺陷，同时恰好也是破绽；只修破绽而不修事实，得到的站点只是"看起来不那么像生成的"，而说的话更少。然后跑那六项相似度测度，并把任何一个无法用材料解释的共享属性，放在与对比度或溢出违规同等的 fail 地位上。
