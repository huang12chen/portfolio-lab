# 作品集改进指南

根据作品材料和目标读者选择相关检查。左列是问题类型，右列是处理与验证方法；具体风格偏好按项目决定。

| 问题 | 可迁移的处理与验证 |
| --- | --- |
| 文章里推荐的网站只知道名字，没有进去 | 文章→资源→具体案例/组件→相关原站；访问和实际交互分级记录 |
| 看着像简历网页，缺少作品 | 将真实材料、贡献、过程与结果形成案例；关于/经历作辅助 |
| 只有数字，不知道真假 | 直接展示对应截图/交付物，数字摘要旁保留口径与时间 |
| 账号很多，不知全部还是选几个 | 精选最有代表性的证据，次要记录作补充；不得把未去重的粉丝数之和称为独立受众，合计须标明未去重与时点 |
| 截图是离职前保存，容易当作当前 | 保留确认的时间语义，快照不写成当前或增长 |
| 雇主素材与个人创作混在一起 | 说明来源与本人职责，作品呈现不等于独立创作 |
| 姓名和邮箱暂不公开 | 留空并保持已有选择，禁止用假身份填完整 |
| 尚未公开的设计不希望上线 | 按素材级别控制范围，不把本地材料自动打包发布 |
| 不知道后续有多少图/视频 | 先完成现有结构，不造无效空格子；后续按真实数量调整 |
| 图里写着无关的“AI 概念封面” | 去掉不帮助读者判断的制作标签，保留必要的来源/示意说明 |
| 字体与标题大小不协调 | 统一角色、行高、字重与中文覆盖，用实际文案试排 |
| 按钮太方/太大，希望更柔和 | 形状和尺寸是品牌选择；统一控件体系，不普遍强制胶囊 |
| 鼠标反馈不明显，移动后找不到 | 深浅背景都有对比，中心点与环清楚；保留稳定命中区与原生可用性 |
| hover 时只剩放大的环，点击没感觉 | 链接、按下、释放、离开分别看真实状态；不是只测静态截图 |
| 点击区域跟随特效漂移 | 内层反馈、外层命中区稳定，滚动后重新测量 |
| 缺少动态反馈，希望更精致 | 根据用途选择磁吸、倾斜、弹簧、光晕或按压；检查复位与减少动效 |
| 想用流体胶囊、抽屉等效果 | 先看具体运行示例，再按真实功能接入；不为效果虚构流程 |
| 不希望抄得像参考网站 | 提炼关系和原理，适配本人内容；不用别人的 logo、文案和素材 |
| 页脚文字太巨大 | 次要联系入口不抢作品主线；大小随品牌和内容调整 |
| 装饰小字和符号太多 | 去掉无用装饰，正文保留必要标点和语义；不是一律删标点 |
| 全部与某一分类看起来一样 | 概览展示真实差异，筛选有有效结果与选中反馈 |
| 各个项目排得太长，开头不知还有什么 | 先给清楚概览；数量少时可同屏比较，多时精选加索引 |
| 点进作品后还要再点 | 直达完整案例，核心材料默认展开，放大/补充可选 |
| 看完不知道怎么回来 | 当前项目名、明确返回列表、相关项目具体名称；测试原生 Back |
| 关于页点“作品”却被带到半页 | 导航标签与约定去向一致；首页顶部和项目区分别命名/处理 |
| 联系入口需要返回原站才能退出 | 当前页临时面板有清楚关闭，保留焦点与滚动恢复 |
| 导航文字重复/重影 | 检查跨页快照和共享元素；不能稳定则保留正常导航 |
| 浏览器中图片偶发加载失败 | 有限重试与明确替代；检查图片解码和 canvas 生命周期 |
| 竖图被硬塞到横幅/方框，主体看不全 | 完整比例或 contain 舞台；检查原图四边及动画后状态 |
| 看似居中却还是随意摆放 | 组容器、图像主体、文字阅读栏分别对齐，图与说明建立关系 |
| 正文挤在宽页面一侧 | 设合适的居中阅读栏，栏内左对齐；不强迫所有文字居中 |
| 打开后不知自己有什么内容 | 定位与概览、明确项目名称、项目开头的职责/材料/结果共同引导 |
| 电脑看全但手机或大宽屏不行 | 包含用户原尺寸、代表断点及真实长文/媒体；无溢出不等于无裁切 |
| 按钮文案像能点，实际只是示意图 | 将示意标识改成描述，主操作必须真正可用 |

这些规则不把一位用户的布局、配色、作品数量和动效偏好固定为通用模板。新任务用它们发现类似风险，再按材料与读者决定实现。
